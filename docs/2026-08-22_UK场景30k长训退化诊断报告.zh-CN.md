# UK 场景 30k vs 8k 验证指标退化诊断报告

日期：2026-08-22
对比对象：`probes/p5_whitebg`（8k 步）vs `ukgs_30k_whitebg`（30k 步），全集 106 个验证帧，masked PSNR（gain=1.0、白背景，与训练评估产物一致）。
产物目录：`C:\Peter\3dgs-runs\diagnosis_30k\`

## 一句话结论

**根因不是巨型飘浮物，而是"曝光增益—模型亮度"联合漂移叠加训练视角过拟合：长训中每图曝光增益持续膨胀（p50 增益 1.108→1.141），把真实场景亮度吸收进增益参数，模型本体渲染随之变暗约 3%，而验证固定 gain=1.0 结账，需求增益最大的左相机验证帧（需 ~1.20）恰好是 p10 尾部，于是尾部塌了 ~1 dB。**

## 证据链

### 1. 逐帧对比（`framewise_psnr.csv`、`framewise_summary.json`）

- 106 帧中 65 帧变差、41 帧变好；delta 均值 -0.47 dB，中位 -0.35 dB。
- **退化完全集中在左相机**：左 53 帧 delta 均值 **-0.93 dB**，右 53 帧 **-0.005 dB**（持平）。恶化最大 10 帧全部是 left，改善最大 10 帧全部是 right。
- 恶化帧空间上聚在 x≈0.7–2.0, y≈-0.6~-2.4（同一段走廊/庭院），但决定性变量是相机侧别而非位置。
- **逐帧最优全局增益与 delta 的相关系数 r = -0.91**：一帧需要的补亮增益几乎完全预测它退化多少。左相机验证帧最优增益 8k=1.161 → 30k=**1.196**；右相机 1.099→1.105。
- 对 30k 渲染施加逐帧最优全局增益后，全集平均 PSNR 回升 **+1.98 dB**（8k 同操作 +1.74 dB）；施加增益后左相机 delta 从 -0.93 收敛到 -0.61 dB。即：**约 1/3 的左侧退化是纯全局亮度**，其余是内容层面的过拟合退化（见 §4）。
- p10 尾部复核：8k 15.78 → 30k 14.82，与外部报告一致。

### 2. 恶化最严重帧的可视化（triptych_*.png、heat_*.png）

三帧 triptych（reference | 8k | 30k）与 |8k−30k| 差异热图显示：差异**弥散于整个有效视场**（墙面、构架、地面同时变化），并叠加地面区域大片羽毛状褐色纹理幻觉；没有孤立的大血团/飘浮物遮挡形态。定性判断：**全局亮度/色彩漂移 + 大面积纹理变化，非局部飘浮物遮挡**。

### 3. 巨型高斯剖析（`scale_census.json`）

| | 8k | 30k |
|---|---|---|
| max 轴长 p50 / p95 / max | 0.072 / 0.203 / 38.3 m | 0.072 / 0.279 / **119.0 m** |
| >1 m 数量（opac_p50） | 2,526 (0.99) | 5,979 (0.9999) |
| >5 m / >20 m | 195 / 7 | 548 / 63 |
| 整体 opacity p50 | 0.12 | **0.96** |
| shN 能量 L2 p50 / max | 0.102 / 0.77 | **0.241 / 2.48** |

巨型高斯 30k 比 8k 多 2.4 倍、近全不透明，约 23–43% 在场景核心盒外——确实存在且更严重，但见 §4，它们对验证指标几乎无贡献。SH 视角相关能量翻倍、整体不透明度从 0.12 硬化到 0.96，是长训"变自信"的签名。

### 4. 飘浮物消融（`ablation_results.json`）——假设被否定

对恶化最大 5 帧，在内存副本上把 max 轴长超阈的高斯 opacity 置零后重渲染（渲染路径自校验：baseline 重渲 PSNR 与训练评估 PNG 一致到 0.001 dB）：

- 剔除 >20 m（63 个）：**+0.001~+0.012 dB**；剔除 >5 m（548 个）：+0.03 dB；
- 剔除 >1 m（5,979 个）：**-0.10 dB（更差）**；>0.5 m 更差 —— 大高斯此时承担着天空/远景的真实低频底色。
- 同帧施加最优全局增益：**+2.1~2.2 dB**。

结论：**飘浮物假设排除**（对指标而言）；亮度假设强确认。

### 5. 过拟合检查（`train_overfit_check.json`）

训练集抽 10 帧、两 checkpoint 均按 gain=1.0 渲染：train delta 均值 **+0.36 dB**（30k 更好，个别帧 +2.6），同时 val delta -0.47 dB —— 标准过拟合签名。且 30k 的 train 帧最优增益整体高于 8k（如 1.098→1.165），与"模型变暗、靠增益补"的漂移方向一致。

### 6. SH 钳位实验（`sh_clamp_val.json`）——SH3 只是次要贡献者

全 106 帧、两 checkpoint、active_sh_degree ∈ {0,1,3}：

| 子集 | deg0 delta | deg1 delta | deg3 delta |
|---|---|---|---|
| all | -0.37 | -0.29 | -0.47 |
| left | -0.78 | -0.69 | -0.93 |
| right | +0.04 | +0.10 | -0.00 |

把 SH 钳到 DC 后左侧退化仍有 -0.78 dB → **高阶 SH 只解释 ~0.15–0.2 dB**，退化主体在 DC 色彩/几何纹理层。另注意两个模型都在 deg1 时验证最优（SH2-3 带对 val 是净负贡献）。

## 已排除 / 已确认的假设

| 假设 | 结论 | 证据 |
|---|---|---|
| 大尺度飘浮物压垮验证 | **排除** | 消融 ≤+0.03 dB，剔 >1 m 反而更差 |
| SH3 视角颜色过拟合是主因 | **降级为次因**（~0.2 dB） | deg0 钳位后左侧仍 -0.78 |
| 曝光/亮度漂移 | **确认为主因** | r=-0.91；增益校正 +2.0 dB；左相机独占退化；train 增益需求同步上移 |
| 训练视角过拟合（几何/纹理层） | **确认为次因**（~0.4–0.6 dB，左侧） | train +0.36 vs val -0.47；增益校正后左侧仍 -0.61；热图大面积纹理幻觉 |
| 噪声注入 30k 不停 | 未单独定罪 | means lr 末端已衰减到 1%，噪声幅度极小；与 refine 停在 25k 的组合列入实验 E |

## 修复建议（按优先级排序，均可单变量验证）

1. **锚定曝光增益的零点（去除增益-亮度简并）**——首选。
   方案 a：每步把 log_gains 减去其均值（投影到零均值子空间），使"全局亮度"自由度只能留在模型里；方案 b：把 `regularization_weight` 从 1e-2 提高到 ~1e-1，或改为对**均值**的强惩罚 + 对离散度的弱惩罚。
   *实验 A（单变量）*：同 `ukgs_30k_whitebg_config` 仅加零均值投影，重跑 30k；判据：val 逐帧最优增益均值从 1.15 回到 ≈1.0，p10 ≥ 15.78，左右相机 delta 对称。
2. **按全集 val PSNR 选优 checkpoint（best-val 而非 latest）**。
   *实验 B*：重跑一次保存全部中间 checkpoint（checkpoint_every=2000），画 val PSNR-vs-step 曲线找拐点（预计 8k–12k 附近），同时量化"多训多坏"的时间结构。
3. **SH 带宽收敛：sh_degree=1（或 2）+ 对 shN 加 L2 正则**。
   *实验 C*：同配置仅改 `sh_degree: 1` 重跑 30k；判据：val 全集 PSNR ≥ 现 30k + 0.2 dB，另有显存/速度红利。
4. **尺度上限 clamp（卫生项，非指标救星）**：refine 后将线性 scale clamp 到场景对角线 ~1%（≈0.5 m）或加 max-scale 正则。预期对 PSNR 中性（消融已证明），但消除 119 m 病态、改善新视角外推。
   *实验 D*：加 clamp 重跑 8k 探针验证无害性（|ΔPSNR|<0.05 dB 且 max scale <1 m）。
5. **refine/noise 调度对齐**：`noise_injection_stop_iter: 25000` 与 refine 同停，单变量重跑看 p10；lr 已衰减，预期影响小，优先级最低。
6. **cap 降低（1M→0.5M）不建议单独做**：无证据表明数量本身伤害验证指标；若做，与实验 B 曲线联合解读。
