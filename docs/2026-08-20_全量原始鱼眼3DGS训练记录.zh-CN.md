## 修改内容

- 新增 `--use-imgpose --image-source camera` 路线：读取 `ImgPose.txt` 的所有可用姿态，并使用录制标定中的两套 `OPENCV_FISHEYE` 内参。
- 生成 COLMAP 4 完整二进制模型（trivial rigs/frames/cameras/images），保留 LiDAR 彩色点作为 3DGS 初始化点。
- 原始鱼眼图不去畸变；通过 `S1_KEEP_FISHEYE=1` 把 k1-k4 传入 3DGUT，并用圆形 mask 排除无效黑边。
- 缺少 `images_<factor>` 时自动从 `images/` 生成 PNG 缩放缓存。
- Windows 构建固定 SM 12.0、RGB 通道和必要模块，并对 MixedBatch 路线规避不需要的 ParallelBatch 链接问题。
- 精简 Windows 构建未包含仅由 MCMC 位置噪声注入使用的基础协方差算子；本次训练设置 `noise_injection_stop_iter=0`，保留 MCMC relocation 和 densification。

## 验证方式

1. 转换器测试：`python -m unittest discover -s tests -p 'test_s1_to_colmap.py' -v`，5 项通过。
2. 数据模型：666 张有姿态的 `camera` 原始图、2 个鱼眼相机、666 个 frames、2 个 rigs、1,019,218 个 LiDAR 初始化点；没有从 `undistort` 取图。
3. CUDA 烟测：5 步 3DGUT 前向、损失、反向、检查点和 PLY 导出成功。
4. 正式训练：4 倍缩放、3000 步、姿态优化、MCMC，最终 1,100,000 个高斯。
5. 验证集：84 张，PSNR 15.7439、SSIM 0.4700、LPIPS 0.5698，平均渲染耗时 0.00836 秒/图。
6. PLY 检查：1,100,000 个顶点、59 个属性；位置、透明度、尺度和旋转属性全部为有限数值。
7. 最终 PLY SHA256：`DE9653F03AF406EF6821B6B7B12CD824DF8A0090B3063B7C5E28D5E81307B07D`。
8. 最终检查点 SHA256：`2AD48F8794766A6D43B9CB92D8B153D63ADA4B0C74C058A4474BE5E5A97E2764`。
