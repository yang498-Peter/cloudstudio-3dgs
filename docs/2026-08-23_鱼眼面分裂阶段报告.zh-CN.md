# 2026-08-23 鱼眼面分裂阶段报告（machine-b）

用户指令"尽快优先做鱼眼面分裂"下达后约 7 小时的完整记录。所有指标为 106 帧全集 masked 值，**f2 验证口径**（与 f4 时代的 17.07 等数值不可跨口径比较）。

## 一、从零到全链路（~2 小时）

| 组件 | 说明 |
|---|---|
| 面规划器 `geometry/fisheye_faces.py` | 前向面(45°×1.1) + 自验证 ring（half-FOV 30-40°、方位重叠 15%、重力对齐、按源像素密度定分辨率）；真实 190° S1 标定→**11 面/镜头**（front 1822² + ring 1208-1256²），覆盖率 100% |
| GT warp `data/face_warp.py` | KB4→pinhole 重采样（bilinear+缓存网格）、保守 mask、稀疏 LiDAR forward-splat z-buffer；**半像素约定统一**（规划器/gsplat 像素中心 (i+0.5)） |
| 离线缓存 `tools/build_face_cache.py` | 多进程，938 图×11 面=**10,318 样本，0 跳过**，签名 manifest，~25GB |
| `FaceCacheDataset` | pinhole TrainingSample、z→ray-range 换算图、"base::face" 曝光共享契约 |
| trainer/backend | camera_model 分支：fisheye=3DGUT+UT+RGB-Ed(命中距离)，pinhole=classic+global-z+RGB+ED(z-depth)+可选 antialiased |

首跑摩擦 5 处（identity 透传、稀疏面零深度监督、z-order 断言、RGB-Ed 限制、manifest 属性），全部当场修复入库。

## 二、两大红利 + 一个 bug 修复

1. **速度 ~8×**：面渲染只涉及视锥内高斯，8k 步+全集评估 **19 分钟**（f2 鱼眼同规模 2.5 小时）——探针迭代周期从小时级降到 20 分钟。
2. **antialiased 解锁**：面是 pinhole（UT 关闭），gsplat 的 Mip-Splatting 2D 补偿不再被 3DGUT 排斥，P14/P15 对照证明其净贡献为正。
3. **深度双重缩放 bug**：既有 fisheye 路径 RGB-Ed(eval3d) 输出本就是欧氏命中距离，早期面训练再乘 z→range 因子=角落最多放大 1.4×。修正后深度 MAE 6.24→5.18。

## 三、探针链与预设定版（P13→P16，每发 20 分钟）

| 探针 | 变量 | PSNR | SSIM | dMAE | 结论 |
|---|---|---|---|---|---|
| P13 | 面分裂首跑（旧栈） | 15.25 | 0.4301 | 6.24 | 冒烟通过，曲线单调 |
| P14 | +UT-off+aa+深度修正 | 14.68 | 0.4349 | 5.30 | 几何大赚、外观回撤 |

**面域正式预设**：face 监督 + antialiased + 深度语义修正 + lidar 0.02 + fast LR 调度 + golden 选优。

**跨制式的共同规律（当前最重要的未解问题）**：所有 run（鱼眼/面、新旧栈、任意调度）都在 cap 于 3-5k 步饱和后进入"重排期"，验证指标停滞或缓降——"越训越差"的本质嫌疑已收敛为**容量饱和后的 MCMC 动力学**。P17（cap 4M）正在直接验证容量假设；根治方向为 error-weighted 抽样 v2（α·T 真聚合）与 densification 质量（双参考清单 #5/#15）。

## 五、下一步（按价值排序）

1. P17 cap-4M 判读：若解锁爬升→容量假设成立，全分辨率时代需要 4M+ 预算（显存充足：2M 仅 3.8GB）；
2. error-weighted v2（raster bwd α·T 聚合）替换 v1 中心采样；
3. PPISP 接线（左右相机亮度差的物理解）；
4. 面域 golden 评估升级：用面渲染做 golden（现在仍是 f2 鱼眼），消除口径折损；
5. LPIPS 离线评估纳入验收（Mip 对标的标准指标）。
