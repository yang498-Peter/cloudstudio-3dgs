## 4. 开工前必须先决的阻塞

1. **磁盘**：50 GB 可用 < 57–75 GB 估算（§1）。
2. **GPU 共用**：8 个 GPU 步骤（A0、A1、A2、A4、G、M-smoke、N、P）都要排在算法臂之后；`pipeline.py queue --after` 只覆盖训练步。
3. **Mask R-CNN 权重文件路径**未找到（A0 必填）。
4. **时间同步需要先有检查点**（A1），SOP 第 2 步在本子集上不是零成本。
5. **1.0 亿点 LAS 的口径**：E 的 `--max-points`、F 的单 worker RAM、J 的 `--voxel-decimate-m` 三处要先决定，否则 E/F 时长与 J/K 体积、P 的显存都不可控。
6. **子集时序间隔 3.5 s** 对 hloc 时序配对与时间同步插值的影响未验证；若 A5 注册数 < 900 或 A6 不收敛，应考虑改用连续时段子集而非均匀抽样。
7. **`pipeline.py` 的竞品参考路径**为必填且被 `arm` 真正消费（§O.5）。
