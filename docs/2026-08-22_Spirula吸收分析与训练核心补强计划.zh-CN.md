## 2. 逐项机制分析

### 2.1 训练配置与预设（TrainConfig.h）

全部默认值见 `src/config/TrainConfig.h` 的 `SS_CONFIG_FIELDS` 表。关键预设（`train_apply_preset`）：

- `quality` 宏（`train_resolve_macros`）：**cap_max 与 num_iterations 成对调**——low=20万/15k、medium=100万/30k、high=300万/50k、ultra=1000万/80k。注释明说"只提一个而不提另一个，就是把时间花在永远不会被 refine 的 splat 上"。
- `in-the-wild` 预设（行人/干扰物场景，直接对应我们的 person-mask 数据）：`distraction_robustness=strong`、`noise_lr 10→0.1`（默认 80→0.8 的 1/8）、`erank_reg=0.1`、`means_lr 5e-5→1e-7`、`sh_degree_warmup_every=0`（SH 不解锁，防止视角相关色"记住"行人）、`outlier_threshold=10`。
- `floater_suppression` 宏：mild = depth_distortion_reg 0.01 + rgb_distortion_reg 0.01 + sh_reg 0.01 + max_screen_size 0.2/hardness 1.25；strong = 0.03/0.05/0.05/0.1/1.1。

### 2.2 Densification：MCMC + 修订版（长轴分裂 + loss-map placement）

**调度**（`src/engine/EngineDensify.cpp`）：
- 停止条件：`step < max(refine_stop_iter=25000, max_steps - refine_stop_num_iter=5000)` —— **最后 5000 步保证无 densify 的纯收敛期**。
- 每步（不只 refine 步）先跑 `densify_clip_scale_tensor`（见 2.3）。
- 每 `refine_every=100` 步：relocate（回收死 splat）+ add（`growth_factor=1.05` 几何增长到 cap_max）。
- MCMC 噪声每步注入，`noise_scalar = noise_lr * (noise_lr_final/noise_lr)^progress`，默认 **80 → 0.8 指数衰减 100 倍**。

**修订版噪声**（`src/shaders/densify.slang: revised_add_noise_3dgs`，注释写明设计动机）：
- `noise = sqrt_covar · randn * min(0.05 * scaler * extend * (1-opac)^150, 1.0)`，其中 `extend = sqrt(2·ln(max(255·opac,1)))`。
- 要点：噪声沿 **sqrt(scale)** 各向异性（介于 MRNF 的 identity 和 MCMC 的 covar 之间）；`(1-opac)^150` 让只有低透明度 splat 才动；`min(...,1)` **硬钳噪声步长防止产生 outlier**（注释：outlier 会破坏 viewer 排序精度）；invisible（radii<=0）不动，让其 scale 衰减直到被 relocate。

**长轴分裂**（`long_axis_split_3dgs`，引 arXiv 2508.12313）：
- 找最长轴，`d = 0.5·exp(max log_scale)`；新 scale：长轴 ×0.5（log+log0.5）、其余两轴 ×0.85；两个子 splat 沿长轴 ±d 分开。
- 分裂后不透明度：`new_logit = log(k / (1 + exp(-logit) - k))`，k 由 `long_axis_split_opacity_k = (0.5, 0.6, 8000)` 线性调度（8000 步从 0.5 升到 0.6）。

**Loss-map placement**（这是我们缺口里的 error-map aware densification，完整实现）：
1. 每步 loss 反传时生成 per-pixel loss map（`densify_loss_map_mode` 默认 `ssim_cs` —— SSIM 的对比度×结构分量；另有 `robust_edge_aware`：BT.601 luma 残差 → 逐图 Tukey biweight（cutoff=分位数 0.9/强模式 0.75）→ Canny 边缘 + NMS，见 `DensifySplitFilter.cu:robust_canny_residual_tensor`，同时满足"渲染已匹配处为零、DC 漂移无梯度、超分位数残差视为干扰物压为零"）。
2. map 条件化：`normalize_clip_map_inplace_tensor`（中位数归一、clip 分位数、幂 `densify_loss_map_power=4.0`）。
3. rasterizer backward 里把 loss map 按 `sum(w·α·T)` 聚到每个 splat（accum mode 默认 avg），跨相机累计 `densify_update_weight`（score_mode 默认 mean，median 是随机化乘法逼近中位数的 O(1) 内存实现，`DensifyScoring.cu:260`）；`score_power=0.4` 压重尾，`score_clip_quantile` 防单点垄断。
4. relocate/add 的 src 用 **weighted sample without replacement** 按该 score 抽样（`Relocation.cu`），dst 是 `sigmoid(opac) <= min_opacity=0.005` 或**任何参数非有限**的 splat（`compute_relocation_mask_kernel` 用一个 dot 混合表达式一次检出 NaN/Inf —— NaN splat 自动回收）。

### 2.3 防巨型高斯 / 长训退化机制（对我们 30k 崩溃最重要）

**每步视角空间尺度钳制**（`DensifyScoring.cu:densify_clip_scale_kernel`，每个训练步都跑）：
```
oversize = radii[i] / max_screen_size          // radii 是无量纲视角尺度（见下）
oversize = min(oversize, clip_hardness=1.5)    // 每步最多收缩 log(1.5)
if oversize > 1:
    log_scales[i] -= log(oversize)             // 三轴同乘收缩
    logit_opac[i] = min(logit + 3*log(oversize), max(logit, 5.0))  // 提高不透明度
```
- `radii` 定义（`projection_utils.slang:view_radius_3dgs`）：`r/(d + sqrt(d²-r²))`，r=最长轴×extend，d=相机距离 —— **是所有可见相机下的角尺度（0~1），与分辨率和场景尺度无关**。默认 `max_screen_size=0.3`。
- 提不透明度那行注释："this encourages being relocated to" —— 在 MCMC 语义下，把超大 splat 变成高 opacity 是让它成为 relocation 的采样目标，被分裂掉，而不只是压制。
- 另有 `max_world_size`（默认 inf，硬 clamp `log_scales <= log(max_world_size·scene_scale)`，不动 opacity）—— 一行代码的保险丝。

**尺度/形状正则**（`src/shaders/per_splat_losses.slang`，在 fused 优化器内以 weight/N 施加）：
- `mcmc_scale_reg_3dgs`：**作用在 log-scale 上**（不是 MCMC 论文的 exp 后），乘 1e-2 系数换算，默认 `scale_reg=0.01`。注释明确说标准 MCMC 的 post-exp 版本 not scale invariant —— log 域版本对大 splat 的惩罚是常数梯度，不会被 exp 放大到无穷，也不会对小 splat 无感。
- `mcmc_opacity_reg`：`0.01 · sigmoid(opac)`，持续把不用的 splat 压到 min_opacity 以下送去回收。
- `erank_reg_3dgs`：有效秩正则 `r = exp(熵(s1,s2,s3))`（s 为归一化方差），`reg = max(-log(r-0.99999), 0)`，防针状/面片状退化；`erank_reg_s3` 额外惩罚最小轴占比（meshing 用）。默认 0，in-the-wild 0.1。
- `scale_reg_3dgs`（旧式）：`max(轴比, max_gauss_ratio=10) - 10`，默认权重 0。
- `quat_norm_reg`：`|q| - 1 - log|q|`，权重 0.01（防四元数范数漂移改变有效 lr）。
- `sh_reg=0.001`：优化器内实现为**带死区的权重衰减**（DC 在 ±0.5/kSh0 内不惩罚，超出部分线性拉回，`FusedGeometryOptim.cu:342`），meshing 预设 10.0 直接杀 SH。

**LR 调度**（`src/app/TrainerCore.cpp:scheduled_lr`，均为 `lr·(lr_final/lr)^(step/max_steps)` 指数）：
- `means_lr 1.28e-4 → 1.6e-6`（80 倍衰减；注意基数比 gsplat 的 1.6e-4 略小是因为 scale-agnostic mean，见 2.7）
- **`scales_lr 0.02 → 0.005`（4 倍衰减）—— scale 学习率也衰减**，quats/opacities/features 恒定。
- 信任域 eps：`eps_tr = 1e-6 · 0.01^progress`。

### 2.4 损失函数组成（EngineLoss.cpp / per_pixel_losses.slang / TrainerCore.build_loss_weights）

- photometric：`(1-ssim_lambda)·归一化(L1/L2/YUV 组合) + ssim_lambda·(1-SSIM)`，`ssim_lambda=0.2`；fused SSIM 11×11（`FusedSSIM.cu`），mask 感知。
- **多尺度 loss**：avg-pool 金字塔，最多 4 级；`loss_scale_min_pixels=1920` 自适应——按当帧渲染短边自动决定级数（1999px→1 级，4000→3 级），mask 用 masked-avg-pool 保持各级可比，粗级梯度均匀散回 4 子像素。
- 深度监督：**log 空间 Pearson 相关**（尺度不变，累计 x/y/xx/yy/xy 五个矩），默认权重 0（我们的 LiDAR ray-range 是 metric 的，比这强）。
- 法线监督 `normal_supervision_weight=0.01`：同时对 render-normal 和 **depth→normal**（从渲染深度微分出的法线）与参考法线做 pairwise normal loss；`normal_reg_weight=0.04`（warmup 6000）是 render-normal vs depth-normal 的**自洽正则，无需 GT**。
- distortion regs（Mip-Splatting 式沿射线分布集中度，D = W·S - C²，来自 raster forward）：depth/normal/rgb 三通道，默认 0，floater 抑制宏开启；`distortion_reg_warmup=6000` 线性升权。
- alpha：mask 监督 `alpha_loss_weight=0.1`（AlphaSup 压超出 mask 的 α，AlphaSupUnder 反向）；`alpha_reg` = `4α(1-α)` 二值化熵。
- `overexposure_reg`：`mean(max(-x, x-1, 0)²)` 直接在 splat 域 RGB 上加梯度（防曝光补偿把内容推出 [0,1]）。
- LPIPS **刻意不内置**（`src/app/EvalMetrics.h` 注释：需要 AlexNet/VGG，放在 `reference/python/eval_lpips.py` 离线算 `--save-eval-images` 的 PNG）。

### 2.5 Bilateral Grid + PPISP（空间变化曝光校正）

- **PPISP**（`src/shaders/ppisp.slang`，**上游是 Apache-2.0 的 nv-tlabs/ppisp**）：每相机参数链 = exposure(`exp2(p)`) → vignetting（3 通道各自 5 参：光心 cx,cy + r²/r⁴/r⁶ 多项式，clamp[0,1]）→ 颜色（RGI 空间 homography，由 4 个 ZCA 白化 latent 控制点算出）→ 可选 CRF（toe-shoulder 或 RQS 有理二次样条）。默认 `ppisp_param_type=no_crf`（24 参/相机）。
- PPISP 正则（默认权重）：exposure 均值 smooth-L1(β=0.1) w=1.0；vig 光心 0.02；vig 非正性 relu 0.01；vig/CRF 通道方差 0.1；颜色 latent 均值 smooth-L1(β=0.005) w=1.0。**均值型正则只约束数据集均值为 0，允许单帧自由** —— 与我们的 per-frame L2 prior 思路一致但更松。
- **Bilateral grid**（`src/kernels/bilagrid/`）：默认开，`bilagrid_shape=16×16×8`（x,y,亮度导引），TV loss 权重 10.0；类型 affine / **ppisp（默认，网格化的 PPISP 变换）** / loglinear（log 域线性，纯曝光型）。几何版 bilagrid（8×8×4）作用在 **GT depth/normal 侧**（校正单目网络的仿射歧义），TV 10.0。
- 优化器：默认 **Adagrad**（`bilagrid_adagrad_lr=0.04`，`ppisp_adagrad_lr=0.1`）而非 Adam——稀疏访问的网格参数用 Adagrad 更稳。
- **color_shift_reg**（`src/kernels/loss/ColorShiftReg.cu`，README 说的 "modified...without unwanted color shift or darkening" 的实现）：`R = w·||EMA[mean_pixel(sign(post-pre))]||²`，惩罚数据集级的校正方向漂移（所有帧一起变暗/偏色），EMA 周期 750 步，在 bilagrid/PPISP backward 之前注入 post 端梯度，让各变换的 vjp 自己认领。默认 w=0（预设可开）。这直接回答"曝光补偿吃掉真实信号"的经典病。
- 顺序：render → background → sRGB → PPISP → bilagrid（`apply_ppisp_before_bilagrid=true`）→ loss。

### 2.6 Fisheye warp_to_pinhole 面分裂（`src/app/GeometryWarp.cpp` + `src/data/PostSplit.cpp` + `src/engine/EngineSetupWarped.cpp`）

- 面规划（常量都在 GeometryWarp.cpp 顶部）：**前向面** ±45°×1.1 重叠；外圈由 **1~3 个 ring** 覆盖，每 ring 4~12 个"直立正方形面"（half-FOV 钳在 30°~40°，30° 时 180° 镜头恰好 8 面），ring 内探 40° 压过前面边缘、外扩至镜头 FOV+3°，邻面方位角重叠 15%，ring 间叠 10°。每面用 `upright_frame` 对齐重力（-y up）——**理由：单目深度/法线网络带重力先验**。
- 面分辨率 = **该方向源镜头的每弧度像素密度**（`source_density` 数值差分实测），不是输出分辨率，上限 4096/面；等距柱状投影为常数 `W/2π`。
- 融合权重：`face_weight` 在面外缘 20% 内 smoothstep 降到 0（C1 跨缝）。
- 训练接线（PostSplit.cpp）：每个 fisheye/equisolid（`warp_to_pinhole`）或 equirect（默认总是分）相机展开成 K 个**零畸变 pinhole 子相机**（各自 c2w = R·axes^T，intrins 来自面规划）；K==1 不分。GT 上传时 fused warp（`EngineSetupWarped.cpp`：字节图直接 warp 成 per-face float，**不落全分辨率中间图**）；深度输出为 per-face ray depth，法线旋进面坐标系。FOV mask 标记无覆盖像素。
- `360-camera` 预设：`warp_to_pinhole=true + primitive=mip + mask_boundary_offset=-0.025`（mask 边界内缩 2.5% 防边缘伪影）。
- 对我们的意义：**这是绕开 2912² 全分辨率 batch-state int32 上限的正统路径**——每面 ≤4096 上限但实际由密度定（190° 镜头 → 前面 + 8~12 ring 面，每面约千级像素边长），单次渲染像素数下降一个量级，还顺带让 3DGUT 不必处理 >90° 单相机。代价：一帧变 K 帧（可当独立训练样本轮流采样，Spirula 就是这么排 batch 的）。

### 2.7 显存管理 / packed / 量化（8GB 训 10M SH3 的来源）

- `quantization_level=1`（默认）⇒ `sh_optim_bits=8`（Adam m/v 联合 (u,√g2) AoS 编码，每 SH 系数 6 字节）、`sh_value_bits=16`（SH 值本身 16-bit 块量化）、`non_sh_optim_bits=16`。块大小 256 splat，**每块存 (min,max) bounds，FPBO 写回时块内 reduce 自动扩界**——densify 复制子 splat 时允许 clip，一步内自愈（`EngineDensify.cpp:53` 注释）。
- 梯度也可块量化 16-bit（`EngineLoss.cpp:_alloc_grad_buffers` grad-quant 路径），非原子 requantize-accumulate。
- `use_fused_proj_bwd_optim=true`：**projection backward 与 Adam step 融合成一个 kernel**，world-space 梯度不落显存（3dgs/mip 完全不分配 means/quats/scales 梯度缓冲；3dgut 因 raster bwd 需 atomicAdd 保留三个）。
- `split_batch=true`：子批累积梯度（首子批清零，后续 atomicAdd，optim 时 grad_scale=1/B）。
- 所有大缓冲走 `DevicePool` 槽位复用 + 高水位。
- `use_per_splat_bias_correction=true`：**每 splat 独立 Adam 步数计数器**（`bias_correction_steps`，relocate 时 dst 继承 src 的步数）——新生 splat 的 bias correction 从头算，等效于新 splat 短暂高 lr，收敛更快且不惊扰旧 splat。
- `use_scale_agnostic_mean=true`（`ScaleAgnosticMeanOptim.cu` / `FusedProjectionBwdOptim_kernel.cuh:519`）：mean 的 Adam 一阶矩用 `sqrt_covar·grad·sqrt(2ln(255α))`（无量纲化），二阶矩配 `radii·0.6` 分母——**means_lr 变成无量纲**，大远处 splat 与小近处 splat 步长自适应，不需按场景尺度调 lr。这是"MRNF 思路但局部自适应"的实现。

## 4. 对 30k 退化问题（val PSNR 尾部崩 + 119m 巨型高斯）的直接建议

按嫌疑排序的组合拳（Spirula 用**七层**防御同一问题，我们目前接近零层）：

1. **立刻加两条硬钳**（半天，先止血）：
   - 世界尺度 clamp：每个 refine 步 `log_scales.clamp_(max=log(0.05 · scene_extent))`（Spirula 的 max_world_size 路径，不动 opacity）。
   - 视角尺度钳（如已有 radii/2D 半径输出）：角尺度 > 0.3 的 splat 按 `log(min(oversize,1.5))` 乘法收缩并 bump opacity。119m 高斯当天消失。
2. **noise 衰减调度**（最可能的 PSNR 尾部崩根因）：gsplat MCMC 的 `noise_lr` 恒定注入 `covar·randn·lr·op_sigmoid`；30k 长训中后期它变成纯扰动。改成 `noise_lr(t) = init·(final/init)^(t/T)`，比例 100:1；同时确认 refine 停止后（我们 refine_stop 是多少？）噪声是否还在打——Spirula 噪声不停但已衰减 100 倍。
3. **给最后 ~15% 步数留纯收敛期**：`refine_stop = min(refine_stop_iter, T - 5000)`，期间无 relocation/add/split，只有（已衰减的）噪声和 lr 尾部。我们“30k 比 8k 差”与“8k 探针在 refine 活跃期、30k 终点在退化累积后”一致——收尾期能把两者对齐。
4. **scales_lr 衰减**：加 0.02→0.005（或等比 4:1）指数衰减。scale 恒定 lr + 恒定噪声是大高斯持续膨胀的正反馈通道（一步大 grad 就能让 exp(scale) 爆炸，Adam 二阶矩追不上）。
5. **log 域 scale reg（0.01×1e-2）+ opacity reg（0.01）**：把 MCMC 的 opacity/scale 正则从 exp 域换到 log 域，尺度不变、对大 splat 是恒定回拉。
6. **诊断动作**（验证根因用）：dump 30k checkpoint 里 scale P99/P999 随步数曲线 + 巨型高斯的出生史（哪一步开始膨胀、是否 relocation 产物、opacity 轨迹）。若巨高斯 opacity 低——是噪声/scale-lr 通道；若 opacity 高——是 densification 抽样把它当靶子复制了（那就更需要 #1 的 opacity bump + 长轴分裂而非整体复制）。
7. 若数据含行人/移动物（我们有 person mask），参考 in-the-wild 预设整套：noise 10→0.1、means_lr 5e-5→1e-7、erank 0.1、SH 渐进解锁**关闭**（sh_degree_interval=0，我们现在 1000 反而可能让 SH 记住残留干扰）。

预期验收：30k ≥ 8k 探针（val PSNR）；max scale < 场景直径 5%；PSNR 曲线最后 5k 步单调不降。
