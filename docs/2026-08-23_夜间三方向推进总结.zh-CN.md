# 2026-08-23 夜间三方向推进总结（machine-b）

用户核准的三个方向全部落地并验证完毕：**error-weighted MCMC v2**、**LiDAR 法线平面正则**、**Gaussian 健康度量**。本夜最大的收获不是某个指标涨了多少，而是**验收体系从单一 PSNR 升级为四表并列**，并因此发现了两个此前被 PSNR 掩盖的真相。

## 一、Gaussian 健康度量：把病态变成数字

新工具 `tools/gaussian_health.py`（11 单测，纯 CPU，5.6 秒扫 200 万高斯）正式量化四类病态：

- **尺度病态**：giant（>0.5/1/5/20m）与 needle（轴比 >10/30/100）分档普查
- **透明度**：dead / fog / hard 三段占比
- **漂浮物（formal definition）**：可见高斯（opacity>0.1）到 LiDAR 实测点云的最近距离，>0.3/1/5m 分档 + 其平均不透明度与尺寸
- **墙面/地面**：RANSAC 主平面上的中心法向 RMS、等效厚度 p50/p95、**高斯最短轴与平面法线夹角**（贴合度）

## 二、两个被 PSNR 掩盖的真相

### 真相 1：PSNR 冠军的几何是脏的

| 模型 | 全集 PSNR | 漂浮物 >0.3m | >1m | NN 距离 p50 |
|---|---|---|---|---|
| 旧栈 faces-60k best@9k（曾是 PSNR 冠军） | 15.83 | 3543 | 597 | 3.0cm |
| 新栈 P16 | 15.40 | 769 | 98 | 1.4cm |

PSNR 高 0.43dB 的"冠军"，漂浮物是新模型的 **4.6 倍**。此前几天的评优标准一直在奖励几何脏但糊得均匀的模型。**双表验收自此固化。**

### 真相 2：长训练累积几何脏污

同一预设、同一代码，仅训练长度不同：

| | P21（8k） | 30k 正式 |
|---|---|---|
| 漂浮物 >0.3m | 326 | **2376**（×7.3） |
| 漂浮物 >1m | 28 | **564**（×20） |
| 漂浮物 >5m | 0 | **27** |
| NN 距离 p50 | 1.34cm | 2.67cm |

"越训越差"这个困扰多日的现象，**在几何层面比在外观层面严重得多**。MCMC 在长训练中持续制造远离实测几何的高斯，而 golden 选优只看 PSNR，拦不住这个退化通道。这解释了为什么容量假设（P17 cap-4M）被否定后一直找不到瓶颈——瓶颈是 densification 的**落点质量**随时间劣化。

## 三、两个新机制：分工互补，都有效

8k 单变量对照（全部对照 P16 基线 PSNR 15.40 / SSIM 0.4400 / dMAE 5.355 / floater 769·98 / 地面厚 8.3cm / 夹角 29.2°）：

| 探针 | PSNR | SSIM | dMAE | floater>0.3m·>1m | 地面厚 | 夹角 |
|---|---|---|---|---|---|---|
| P20（v2 + 法线） | 15.05 | 0.4335 | **4.962** | **187 · 14** | 5.8cm | 10.1° |
| **P21（仅法线）** | 15.25 | **0.4448** | 5.234 | 326 · 28 | **5.4cm** | **8.5°** |

- **LiDAR 法线正则 = 贴平主力**：地面等效厚度 −35%、最短轴夹角 **29.2°→8.5°（−71%）**，且 **SSIM 反超基线**（结构相似度是比 PSNR 更诚实的几何指标），深度也改善。代价仅 −0.15dB PSNR。**已晋级预设。**
- **error-weighted v2 足迹聚合 = 清漂浮主力**：在法线基础上把漂浮物再砍一半（326→187，>1m 28→14），深度再改善 0.27m。代价额外 −0.20dB PSNR / −0.011 SSIM。**列为可选强化项。**

## 四、当前定版与交付

- **面域正式预设**：面分裂监督 + antialiased + 深度语义修正 + lidar 权重 0.02 + fast LR 调度 + golden 选优 + **LiDAR 法线正则**
- **最佳几何模型**：P21（8k）——健康度与 SSIM 最优组合
- **最佳外观模型**：旧栈 faces-60k best@9k（PSNR 15.83，但几何脏，不推荐作为产品交付）
- 交付 PLY：`exports/ukgs_faces_best.ply`（旧冠军）；新预设的交付候选待 P22 权重实验后确定

## 五、下一步（按价值排序）

1. **P22 法线权重 ×3 实验**（进行中）：贴合度还能否进一步、SSIM 是否保持；
2. **漂浮物治理是长训练的关键**：把健康度纳入 golden 选优（现在只看 PSNR），或在 refine 中直接剔除 NN 距离超阈的高斯——这是"越训越差"的根治方向；
3. error-weighted v2 的 30k 验证（8k 已证明清漂浮有效，长训练场景价值可能更大）；
4. LPIPS 接入验收（Mip 对标的标准指标）；
5. 多尺度 loss（Spirula #16）。
