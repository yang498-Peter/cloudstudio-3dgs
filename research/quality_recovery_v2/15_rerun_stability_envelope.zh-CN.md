# 15. 复跑稳定性包络：同一配置跑两次能差多少，以及什么信号能提前看出来

日期：2026-09-15。§1–§6 全部来自磁盘上已有的两对"同配置复跑"产物，没有新训练。**§7 补了第三次 B5 复跑（当天 04:43 完成），把 B5 从 n=2 抬到 n=3；§4 末尾那段"每条配方只有一对复跑"的证据强度声明已被 §7 取代，读到那里请接着看 §7。**

## 1. 数据与对照

两对复跑，配置逐键相同（只差 `output_dir`、`run_id` 和 `lineage` 文字）：

| 对 | 第一次 | 复跑 |
| --- | --- | --- |
| B5（推荐配方：归属遮罩 + 天空 alpha + 替身背景 + cap 6M） | `tile1_B5_cap6_20k` | `tile1_B5_rerun_20k` |
| R1d（旧交付基线） | `tile1_R1d_20k` | `tile1_R1d_rerun_20k` |

**测量侧阴性对照**：两对的 49 个 ROI 面板里，`lv_photo`（照片）与 `lv_ref`（竞品）逐视角**逐位相同**（max |Δ| = 0），ROI 框也完全相同。所以两次读数的全部差异都在**我方渲染**上，不是比较工具、不是选帧、不是亮度归一。

## 2. 结果：形态极稳，光度锐度不稳，而且不是对称抖动

| 指标 | B5 → B5 复跑 | R1d → R1d 复跑 |
| --- | --- | --- |
| 最终高斯数 | 4,654,937 → 4,658,981（**+0.09%**） | 3,336,404 → 3,311,214（**−0.76%**） |
| 最短轴 p50 | 0.342 → 0.345 mm（+0.9%） | 0.319 → 0.312 mm（−2.2%） |
| 长轴 p95 | 20.7 → 20.6 mm（−0.5%） | 46.0 → 46.5 mm（+1.1%） |
| max/min p50 | 16.75 → 16.55（−1.2%） | 24.66 → 25.27（+2.5%） |
| opacity p50 | 0.104 → 0.103（−1.0%） | 0.147 → 0.149（+1.4%） |
| frac<0.1 | 0.493 → 0.494（+0.2%） | 0.431 → 0.428（−0.7%） |
| **ROI 面板中位 ours/ref** | 0.501 → 0.414（**−17.3%**） | 0.366 → 0.315（**−14.1%**） |
| **配对逐视角中位变化** | **−2.5%** | **−19.0%** |
| 配对 p10 / p90 | −18.5% / **+18.1%** | −37.8% / **−1.9%** |
| 符号检验（复跑更好的视角数） | **23 / 49**（≈50%，纯噪声） | **4 / 49**（系统性变差） |
| ROI 内我方 Laplacian 方差中位 | 14.33 → 15.27（+6.6%） | 16.09 → 13.23（−17.8%） |

两条独立结论：

**(a) 面板中位数是脆弱统计量，配对逐视角中位数才可用。** B5 的面板中位掉了 17.3%，但配对中位只有 −2.5%、符号检验 23/49 —— 两次跑在统计上不可区分。面板中位是"49 个含噪读数的中位数"，分布稍微换形状就整体位移。**此前所有按面板中位排名的判臂都应按配对中位复核**（本轮填充扫描不受影响，见 §4）。

**(b) R1d 的复跑差异不是噪声，是系统性的。** 45/49 个视角同向变差、配对中位 −19%、p90 仍是 −1.9%（即几乎没有一个视角变好）。同一配置、同一种子设定跑两次，**整个模型落到了明显更糊的一个解上**。这不是测量抖动，是训练轨迹的分叉。

## 3. 关键的反直觉发现：训练 loss 指不出哪一次更好

R1d 那次**更糊**的复跑，训练指标反而**更好**：

| 窗口 | 训练 PSNR（第一次 → 复跑） | SSIM loss |
| --- | --- | --- |
| 1000–3000 步 | 14.910 → 14.891（−0.019） | 0.4223 → 0.4222 |
| 3000–6000 步 | 17.024 → **17.086（+0.062）** | 0.3949 → **0.3946（更低）** |
| 14000–20000 步 | 19.730 → **19.822（+0.093）** | 0.3560 → **0.3554（更低）** |

**即：ROI 锐度掉 18% 的那次，末段训练 PSNR 高 0.09 dB、SSIM loss 更低。**

对无人值守流水线的直接后果：**任何"按 loss / 训练 PSNR 早停或重掷"的健康检查都会掐掉好的那一次。**这条设计必须放弃，不能写进 SDK。

## 4. 能用的信号：种群轨迹

| 对 | 种群偏差 |Δ N| 的走势 |
| --- | --- |
| B5 | 全程 ≤ 0.32%，末态 0.09%；从未越过 0.5% |
| R1d | 第 1801 步起越过 0.5%，此后长期 1.0–1.8%，末态 0.76% |

两对里，**存活高斯更多的那一次就是更锐的那一次**（R1d 3.336M 锐 / 3.311M 糊；B5 4.6590M 锐 / 4.6549M 糊）。方向与既有结论一致：锐度来自密度与半透明叠层，不来自形状（见 `low-opacity-stack-is-not-dead-mass`、`needles-are-density-not-shape`）。

这给出一个便宜的运行健康检查：**增殖停止时（12k–14k 步）种群已经冻结，此时把 N 与该配置的参考跑对比即可**，不必等到 20k。省下的只有约 6000 步（≈35 min），但代价是零。

**证据强度必须说清楚（本段已被 §7 更新，B5 现在是 n=3）**：写下本段时每条配方只有一对复跑，n=2。"B5 比 R1d 更可复现"有两项独立支持（种群偏差 0.09% vs 0.76%、配对中位 −2.5% vs −19.0%），机制上也说得通（cap 6M 与归属遮罩把轨迹钉住，R1d 的种群自由漂移），**但没有被第三次跑证伪过**。要把它当门禁用，需要各再跑一次（2 × 2 h GPU）。

## 5. 本轮填充扫描不受复跑噪声影响

填充规则的四个点（不填充 / c2 / c0v35 / fill2）共用**同一批四个切片 checkpoint**，差异只在 CPU 侧的合并填充层；合并、导出、渲染、打分全是确定性的。所以那条取舍曲线上**没有训练噪声**，0.444 → 0.369 的锐度下降是精确差值，不需要套噪声带。

## 6. 给 SDK 的结论

1. 判臂与门禁一律用**配对逐视角中位数 + 符号检验**，不用面板中位数。
2. **不要**用训练 loss / 训练 PSNR 做运行健康检查或早停——已实测会掐错。
3. 形态与种群指标（最短轴、轴比、opacity 分位、N）复跑带 < 2.5%，可以直接做 fail-closed 门槛。
4. 光度/锐度门槛必须带噪声带；单条配方的单次读数不足以判负。
5. 运行健康检查放在增殖停止步，比较种群规模与参考跑；偏差超过 0.5% 记为警告并在报告里留痕，**不自动改配置重跑**（改配置重跑就是新臂，按冻结配置纪律必须换臂名）。

## 7. 第三次 B5 复跑（2026-09-15 04:43）：n=2 变 n=3，B5 的三对两两全部不可区分

`tile1_B5_rerun2_20k` 与前两次逐键相同（只差 `output_dir`/`run_id`/`lineage`），20000 步，四对比较的阴性对照全部 PASS：

| 配对 | 配对逐视角中位 | p10 | p90 | stdev | 符号检验 | 判定 |
| --- | --- | --- | --- | --- | --- | --- |
| B5 run1 vs run2 | −2.5% | −17.7% | +17.0% | 16.1% | 23/49 | 噪声 |
| B5 run1 vs run3 | −2.0% | −17.4% | +18.2% | 16.3% | 22/49 | 噪声 |
| B5 run2 vs run3 | **−0.2%** | −7.9% | +6.2% | **10.0%** | 23/49 | 噪声 |
| R1d run1 vs run2 | **−19.0%** | −36.9% | −2.3% | 16.1% | **4/49** | **系统性** |

**种群三跑：4,654,937 / 4,658,981 / 4,656,862——极差 4,044，占 0.087%。**形态三跑同样稳：最短轴 p50 0.342 / 0.345 / 0.337 mm，长轴 p95 20.7 / 20.6 / 20.5 mm，opacity p50 0.104 / 0.103 / 0.103，frac<0.1 0.493 / 0.494 / 0.494。

**可以说的**：B5 这条配方**三跑之间两两不可区分**（三对符号检验 22–23/49，全部贴着 50%），种群极差 0.087%。ROI 锐度的逐视角散布仍然很大（p10/p90 约 ±17%），但那是**单视角读数的噪声**，不是模型之间的差异——配对中位与符号检验都说三次跑到了同一个解附近。

**不能说的**：R1d 只有**一对**复跑。"B5 比 R1d 更可复现"仍然是不对称证据：B5 三对全部为噪声，R1d 那一对是系统性的（45/49 视角同向变差）。要把 R1d 判为"更不可复现"，需要给 R1d 也补第三跑。现在能下的结论是**B5 的可复现性已被三跑证实**，而 R1d 有一次已证实的分叉。

**事故备注**：第三跑在 03:15–03:20 期间与一次比较渲染共享了约 5 分钟 GPU（守卫失效，见台账同日条目）。这只影响墙钟，不影响采样顺序与任何数值，本臂也不计时，故读数有效；如实记录以便复核。
